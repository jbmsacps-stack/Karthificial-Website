## 📚 What We Learned

- Frontend code and database column names must match exactly.
- A small Supabase schema mismatch can break the entire admin content flow.
- Admin panels need careful testing because one logic issue can affect multiple sections.
- Article pages need strong structure, spacing, and thumbnail handling to look professional.
- CSS fixes should be targeted so they do not accidentally affect working components.
- Real dynamic content is better than placeholder cards for a final project.
- Search functionality must be tested with real content, not only empty layouts.
- Visual polishing is not just decoration; it affects how complete and professional the project feels.
- Upload buttons and input fields need proper spacing to make admin tools easier to use.
