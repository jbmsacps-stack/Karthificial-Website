## How We Fixed It

- Reworked thumbnail presentation so it looked more like a proper blog/article website.
- Hid the article thumbnail inside the blog content where it was not needed.
- Improved related article logic to use real website article data.
- Removed or reduced unwanted glow effects from career and resource sections.

- Improved spacing around upload buttons and input fields.
- Continued testing visual issues using screenshots and frontend inspection.

## What We Learned
- Frontend code and database column names must match exactly.
- A small schema mismatch can break the entire admin content flow.
- Article pages need strong structure, spacing, and thumbnail handling to look professional.
- CSS fixes should be targeted so they do not accidentally change working components.
- Real dynamic content is better than placeholder cards for a final project.
- Visual polishing is not just decoration; it affects how complete and professional the project feels.
