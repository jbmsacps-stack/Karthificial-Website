## 📚 What We Learned

- Full-stack deployment requires the frontend, backend, database, and hosting platform to work together correctly.
- Authentication must be tested using fake users, wrong passwords, and real accounts.
- Supabase connection strings and environment variables must be handled carefully.
- `config.js` is important for connecting frontend pages with backend API routes.
- Not every feature needs full automation in the early stage of development.
- A simple moderator-handled password recovery flow can be better during project stabilization.
- Lazy loading improves website performance and makes the site feel more polished.
- Publishing the app and updating the README are important parts of professional project delivery.
