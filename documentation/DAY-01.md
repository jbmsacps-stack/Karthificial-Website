# Day 01 - 19/05/26

## Work Done Today
- Conducted the initial project planning session and finalized the direction of the Karthificial web platform.
- Discussed the target users: 10th and 12th Tamil Nadu State Board students.
- Decided the core modules: Home, Notes, Question Papers, Career Guidance, MCQ, Login, Signup, and Contact.
- Planned the black-and-gold visual identity to give the website a premium educational platform feel.
- Assigned early responsibilities for frontend, documentation, backend research, and GitHub workflow.

## Problems Faced
- The project scope was broad, so the first challenge was deciding what features should come first.
- The team had to align on one design direction instead of building random pages separately.
- We needed a clean GitHub workflow before development started.

## How We Fixed It
- Broke the project into clear modules and decided to build page by page.
- Agreed to use plain HTML, CSS, and JavaScript for the frontend first.
- Planned backend integration separately so the frontend could move fast without waiting for server setup.
- Defined GitHub as the main place to track all work.

## What We Learned
- A strong project needs planning before coding.
- Clear module separation makes team development easier.
- Design consistency is important from Day 1.
- GitHub workflow planning prevents confusion later.
