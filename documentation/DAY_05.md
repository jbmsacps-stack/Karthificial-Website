# 📅 Day 05 — 23/05/2026

## 📌 Daily Progress Report

Today, we started moving the **Karthificial** project from a simple frontend-based website toward a more complete full-stack structure.  
The main focus was to begin backend development, create a proper server folder, and explore **Spring Boot** as the backend framework.

---

## ✅ Work Done Today

- Started backend development for the **Karthificial** project.
- Created a dedicated `server` folder for backend-related files.
- Implemented the first basic backend setup.
- Decided to strengthen the project by moving toward a full-stack architecture.
- Integrated **Spring Boot** into the project structure.
- Added early backend framework support.
- Started preparing the project for frontend and backend connection.
- Maintained the existing frontend structure while introducing backend development.

---

## ⚠️ Problems Faced

- The project direction changed from a mostly static frontend website to a full-stack application.
- Backend setup introduced new complexity compared to plain HTML, CSS, and JavaScript.
- The team had to understand how frontend pages would later connect with backend routes.
- Spring Boot required a proper folder structure and configuration setup.
- Framework decisions created uncertainty because the project still needed to remain deployable.
- The team needed to make sure backend changes did not disturb the existing frontend progress.

---

## 🛠️ How We Fixed It

- Created a separate `server` folder to keep backend files organized.
- Started implementing the Spring Boot backend step by step.
- Adjusted the project direction from frontend-only development to frontend plus backend development.
- Kept the existing frontend pages active while backend work was introduced separately.
- Began planning how frontend pages could communicate with backend routes in the future.
- Treated backend integration as a gradual process instead of changing the entire project at once.

---

## 📚 What We Learned

- Adding a backend changes the overall architecture of a web project.
- Spring Boot needs a proper folder structure, configuration, and development flow.
- Frontend and backend should be planned as connected systems.
- Backend decisions affect deployment, database connection, authentication, and project scalability.
- Keeping frontend and backend folders separate makes the project easier to manage.
- A full-stack project requires more planning than a static frontend website.

---

## ✅ Day 05 Summary

By the end of the day, the **Karthificial** project had taken its first step toward full-stack development.  
A dedicated backend structure was introduced, Spring Boot integration was started, and the team began understanding how the frontend and backend would work together.
