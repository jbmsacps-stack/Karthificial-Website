# Day 05 - 23/05/26

## Work Done Today
- Started backend development by creating the server folder.
- Implemented the first backend setup.
- Decided to change and strengthen the web framework direction.
- Integrated Spring Boot into the project.
- Added early framework-related frontend and backend structure support.

## Problems Faced
- The project moved from a static frontend direction into a full-stack direction.
- Backend folder structure and Spring Boot setup introduced new complexity.
- The team had to understand how frontend pages would connect with backend routes.
- Framework decisions created uncertainty because the project had to remain deployable.

## How We Fixed It
- Created a dedicated server folder for backend work.
- Started implementing Spring Boot step by step.
- Adjusted the project direction from only frontend to frontend plus backend.
- Kept the existing frontend alive while backend structure was introduced.

## What We Learned
- Adding backend changes the entire project architecture.
- Spring Boot needs a proper folder and configuration structure.
- Frontend and backend should be planned as connected systems.
- Framework decisions must consider deployment, database, and authentication.
