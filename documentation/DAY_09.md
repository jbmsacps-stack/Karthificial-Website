## ⚠️ Problems Faced

- Login and signup buttons appeared briefly even after the user was already signed in.
- The signed-in greeting did not appear consistently while navigating between pages.
- Some frontend sections had alignment and spacing issues.
- Mobile layout problems appeared on certain pages.
- Authentication UI required repeated testing because small timing delays affected the user experience.
- Some visual bugs were difficult to identify until the website was tested carefully.
- The navbar needed more stable behavior across different pages and screen sizes.

---

## 🛠️ How We Fixed It

- Improved local storage usage so user information could be available immediately after page load.
- Updated navbar authentication logic to reduce visible delay.
- Hid login/signup actions while authentication status was being checked.
- Reduced flashing issues in the navbar after login.
- Debugged frontend behavior across multiple pages.
- Adjusted CSS and JavaScript where needed to improve layout stability.
- Tested reported visual issues and corrected them step by step.
- Reviewed mobile layouts and improved responsiveness.
- Continued cleaning documentation so the project looked more professional.

---

## 📚 What We Learned

- Authentication UI needs careful handling because even small delays can affect user experience.
- Local storage can improve frontend consistency when used properly.
- Navbar behavior must be tested across multiple pages, not just the homepage.
- Debugging is not only about fixing broken code; it also includes improving small visual and timing issues.
- Mobile testing is necessary because desktop layouts may not reveal all problems.
- A professional website requires repeated testing, correction, and refinement.
- Clean documentation helps present the project more clearly.
