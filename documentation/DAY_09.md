## Problems Faced
- Login and signup buttons appeared briefly even after the user was already signed in.
- The signed-in greeting did not feel fully consistent while navigating between pages.
- Some frontend sections had visual alignment and spacing issues.
- Mobile layout problems appeared in certain pages.
- Authentication UI required repeated testing because small timing issues affected the user experience.
- Some visual bugs were difficult to notice until the website was tested carefully.

## How We Fixed It
- Improved local storage usage to keep user information available immediately after page load.
- Updated navbar authentication logic to reduce visible delay.
- Hid login/signup actions during authentication checking to avoid flashing issues.
- Debugged frontend behavior across multiple pages.
- Adjusted CSS and JavaScript where needed to improve layout stability.
- Reviewed visual bugs reported during testing and corrected them step by step.
- Continued cleaning documentation so the project looked more professional.

## What We Learned
- Authentication UI needs careful handling because even small delays affect user experience.
- Local storage can improve frontend consistency when used properly.
- Debugging is not only about fixing broken code; it also includes improving small visual and timing issues.
- Mobile testing is necessary because desktop layouts may not reveal all problems.
- A professional website requires repeated testing, correction, and refinement.
