Platform Features

A Learning Website Built for Students and Admins

The public side helps students find notes, question papers, MCQ sets, and career guidance. The admin side helps manage articles, MCQ sets, papers, and notes without manually editing every public page.

The MCQ system is being upgraded with student performance tracking, question analysis, shuffle controls, and weak-question reports so admins can understand where students are struggling.

Content Management

Admins can add, edit, and delete learning content like notes, papers, career articles, and MCQ sets.

Student Performance

Admins can view student MCQ attempts, scores, accuracy, points, time taken, and individual performance details.

Question Analysis

MCQ answers can be analysed per question to see correct rate, wrong answers, unanswered count, and option distribution.

Weak Questions Report

The admin dashboard can highlight questions students answered wrong most often, helping identify weak topics faster.
